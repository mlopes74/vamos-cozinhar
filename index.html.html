Antes de começar, o app precisa da sua chave da API da Anthropic. É ela que faz a leitura das fotos e a criação das receitas.

  1. Acesse console.anthropic.com
  2. Crie uma chave em API Keys
  3. Cole aqui embaixo

A chave fica guardada apenas neste aparelho, no armazenamento do seu navegador. Ela não é enviada para lugar nenhum além da própria API da Anthropic, e não fica dentro do arquivo do app. Nunca compartilhe sua chave nem publique o app com ela escrita no código.
